# Portal Novo
Portal moderno para oferecer cursos gratuitos em tecnologia, comportamento e marketing.

## Como visualizar
Basta abrir o arquivo `index.html` em qualquer navegador moderno. Todo o estilo está em `style.css`.

## Como gerar um preview local
1. Tenha o Python 3 instalado.
2. No terminal, entre na pasta do projeto e execute `python -m http.server 8000`.
3. Abra `http://localhost:8000` no navegador para ver o portal.
